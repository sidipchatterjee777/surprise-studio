# 💖 4-Step Surprise Journey Website (React + Tailwind CSS + Vite)

A complete, customizable 4-step romantic surprise website built with React, JSX, Tailwind CSS, and Lucide Icons:
1. **Step 1 — The Playful Invite Gate:** Dodging "No" button, growing "Yes" button, and unlockable VIP Date Ticket.
2. **Step 2 — Live Relationship Clock & Reasons Deck:** Real-time days/hours/minutes/seconds counter and shuffleable reasons deck.
3. **Step 3 — 8-Photo Memory Carousel:** Interactive memory cards with stories, locations, and heart reactions.
4. **Step 4 — Typewriter Love Letters & Redeemable Coupons:** Wax-sealed "Open When..." envelopes with live typewriter animation and tap-to-claim date coupons.

## 🚀 How to Run Locally
```bash
npm install
npm run dev
```

## 🌐 Free Deployment Options

### Option A: Deploy to Vercel (Recommended — 60 Seconds)
1. Push this folder to a new GitHub repository (or install the Vercel CLI with `npx vercel`).
2. Go to [vercel.com/new](https://vercel.com/new) and import your repository.
3. Vercel automatically detects **Vite + React** and deploys your live shareable link (`https://your-surprise-name.vercel.app`).

### Option B: Deploy to GitHub Pages
1. Push this project to a GitHub repository.
2. Run `npm run build` locally and deploy the `dist/` folder to the `gh-pages` branch, or enable **GitHub Actions (Static HTML / Vite)** under **Settings → Pages**.
